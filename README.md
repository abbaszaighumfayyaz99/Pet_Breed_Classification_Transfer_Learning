Computer Vision, University of Verona, Fall 2026, Abbas Zaighum Fayyaz

This repository compares three strategies for adapting a pre-trained
**MobileNetV3-Small** (ImageNet-1K) to the 37 breeds of the **Oxford-IIIT Pet** dataset:

1. **Full fine-tuning**: the final layer is replaced and the whole network is trained.
2. **Classifier-head training**: the convolutional feature extractor is frozen; only the
   fully connected classifier layers are trained.
3. **Feature extraction + traditional classifier**: the network is frozen, 576-dimensional
   features are extracted after global average pooling, and scikit-learn classifiers
   (Logistic Regression, Linear SVM) are trained on them.

All approaches use the same data split, preprocessing and evaluation protocol.

## Results (held-out test set, 3,669 images)

| Approach | Selected | Trainable params | Time (s) | Train acc* | Val acc | Test acc | Test macro F1 |
|---|---|---|---|---|---|---|---|
| 1. Full fine-tuning | epoch 12 | 1,555,781 | 1617 | 0.992 | 0.879 | 0.818 | 0.815 |
| 2. Classifier-head training | epoch 3 | 628,773 | 635 | 0.948 | 0.891 | 0.842 | 0.840 |
| 3. Features + Logistic Regression | C = 0.01 | 21,349 | 84.7 | 0.988 | 0.876 | 0.857 | 0.855 |
| 3. Features + Linear SVM | C = 0.01 | 21,349 | 98.9 | 0.999 | 0.875 | 0.833 | 0.831 |

\*Accuracy of the selected model on the training images without augmentation.
Times for approaches 1 and 2 cover all 15 epochs, including the validation pass after each epoch.
Time for approach 3 = feature extraction for all splits (84.1 s) + fitting the selected classifier.
Full table: `results/summary_table.csv`.

## Dataset

- **Oxford-IIIT Pet Dataset**: 37 breeds (25 dogs, 12 cats), about 200 images per breed.
- Source: https://www.robots.ox.ac.uk/~vgg/data/pets/
- Authors: O. M. Parkhi, A. Vedaldi, A. Zisserman, C. V. Jawahar, *Cats and Dogs*, CVPR 2012.
- License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0);
  image copyright remains with the original owners.

The dataset (~800 MB) is **not included** in this repository. It is downloaded automatically
by TorchVision into `data/oxford-iiit-pet/`:

```bash
python src/download_data.py
```

Official partitions: `trainval` = 3,680 images, `test` = 3,669 images.
Labels are the 37 breed categories (not the binary cat/dog labels).

## How to reproduce

Run all commands from the `Homework_2` folder, in this order:

```bash
# 1. Data
python src/download_data.py        # download dataset (~800 MB, first run only)
python src/explore_data.py         # images per breed -> results/class_counts_official.csv
python src/make_split.py           # stratified split -> splits/, results/class_counts_split.csv

# 2. Approach 1: full fine-tuning (~27 min on CPU)
python src/train.py --mode full --lr 1e-4 --epochs 15

# 3. Approach 2: classifier-head training (~11 min on CPU)
python src/train.py --mode head --lr 1e-3 --epochs 15

# 4. Approach 3: feature extraction + scikit-learn
python src/extract_features.py     # ~1.5 min
python src/train_sklearn.py        # selects C on validation (~26 min: large C values for the SVM are slow)

# 5. Evaluation
python src/evaluate.py             # test accuracy, macro F1, confusion matrices
python src/error_analysis.py --model 3_features_logreg
python src/error_analysis.py --model 1_full_finetuning
python src/plot_curves.py          # results/training_curves.png
python src/summary.py              # results/summary_table.csv
```

Optional: `python src/inspect_model.py` prints the network structure and parameter counts.

Note: training times in `summary.py` were copied from the terminal output of the runs above.

## Data splits and preprocessing

- The official `trainval` partition is split into **train (2,944)** and **validation (736)**
  with `sklearn.model_selection.train_test_split(test_size=0.2, stratify=breed, random_state=42)`.
  Indices refer to the image order of the official `trainval` list as loaded by
  `torchvision.datasets.OxfordIIITPet`, and are saved in `splits/`.
- The official `test` partition is kept separate from training and model selection.
  Test images are only passed through the frozen network in `extract_features.py`
  (features stored, not used for any decision) and evaluated once in `evaluate.py`.
- The dataset is nearly balanced (93-100 images per breed in trainval, 88-100 in test);
  no class balancing is applied.
- **Validation / test / feature extraction:** the preprocessing bundled with the pre-trained weights:
  resize to 256 (bilinear), center crop 224, normalization with ImageNet
  mean (0.485, 0.456, 0.406) and std (0.229, 0.224, 0.225).
- **Training (approaches 1 and 2 only):** `RandomResizedCrop(224, scale=(0.7, 1.0))`,
  `RandomHorizontalFlip()`, the same normalization.
- Approach 3 extracts features once from non-augmented images.

## Selected models and hyperparameters

Model selection used the **validation set only** (best validation accuracy).

| Approach | Trainable layers | Loss / optimizer | Hyperparameters | Selected | Checkpoint |
|---|---|---|---|---|---|
| 1. Full fine-tuning | all layers | Cross-entropy / Adam | lr 1e-4, batch 32, 15 epochs | epoch 12 | `checkpoints/full_best.pt` |
| 2. Head training | `classifier[0]` (Linear 576→1024), `classifier[3]` (Linear 1024→37); `features` frozen (incl. BatchNorm statistics) | Cross-entropy / Adam | lr 1e-3, batch 32, 15 epochs | epoch 3 | `checkpoints/head_best.pt` |
| 3. Logistic Regression | scikit-learn model only | multinomial log-loss, L2 (lbfgs) | StandardScaler (fit on train), C ∈ {0.001, 0.01, 0.1, 1, 10}, max_iter 2000 | C = 0.01 | `checkpoints/sklearn_logreg.joblib` |
| 3. Linear SVM | scikit-learn model only | squared hinge, L2 (liblinear, one-vs-rest) | StandardScaler (fit on train), C ∈ {0.001, 0.01, 0.1, 1, 10}, max_iter 5000 | C = 0.01 | `checkpoints/sklearn_svm.joblib` |

In all cases the final ImageNet layer (1000 outputs) is replaced by a 37-output layer.
Pre-trained weights: `torchvision.models.MobileNet_V3_Small_Weights.DEFAULT`
(= `IMAGENET1K_V1`, file `mobilenet_v3_small-047dcff4.pth`, 67.7 % top-1 on ImageNet-1K).

## Reproducibility

- Random seed **42** for Python (`random`), NumPy and PyTorch (`torch.manual_seed`),
  for the data split (`random_state`), the scikit-learn classifiers and the selection of prediction examples.
- **Deterministic algorithms were not enabled** (`torch.use_deterministic_algorithms` was not used).
  All experiments ran on CPU; re-running the first training epoch gave identical results.
- Remaining sources of variation: different hardware, number of CPU threads,
  or library versions can cause small numerical differences.
- No test data was used for training, early stopping, feature scaling or hyperparameter selection.
